2. TARGET ARCHITECTURE (IMPLEMENT EXACTLY)
================================================================================

  2.1 Modules
  -----------

  [A] DistilBERT
      - transformers: DistilBertModel + DistilBertTokenizer
      - model name: distilbert-base-uncased
      - FROZEN (requires_grad=False for all params)
      - Use [CLS] hidden state → (B, 768)

  [B] TextProj
      - Linear(768, 64) + LayerNorm(64)
      - Output e ∈ R^{64}
      - TRAINABLE

  [C] Text2Traj
      - MLP: 64 → 256 → ELU → traj_dim
      - traj_dim: define from geometry (see §3); e.g. 10 horizons × 2 (xz) = 20
      - TRAINABLE
      - Predicts desired trajectory features from text

  [D] DecompressorNet  (Holden)
      - MLP: feature_dim → 512 → ELU → 512 → ELU → pose_dim
      - x → y

  [E] StepperNet  (Holden)
      - MLP: (feature_dim + control_dim) → 512 → ELU → 512 → ELU → feature_dim
      - (x, c) → x_next

  [F] ProjectorNet  (Holden)
      - MLP: query_dim → 512 → ELU → 512 → ELU → feature_dim
      - Dropout 0.3 on hidden layers recommended
      - q → x_star

  2.2 Tensor definitions (MUST implement)
  ---------------------------------------

    # After STEP 1 lock (this Kaggle set): D=263, pose_dim=66
    vec   = load new_joint_vecs[id]           # (T, 263)
    mean, std = Mean.npy, Std.npy             # (263,)
    x_t   = (vec[t] - mean) / (std + 1e-8)    # feature_dim = 263

    joints = load new_joints[id]              # (T, 22, 3)
    y_t   = joints[t].reshape(-1)             # pose_dim = 66  REQUIRED

    Do NOT use y_t = x_t unless joints file missing (should not happen after STEP1 PASS)

    From joints, compute for each t:
      state_t  = geometric state features (root xz vel, facing, feet)  # state_dim
      traj_t   = future root xz offsets at fixed horizons in root frame # traj_dim

    e     = TextProj(DistilBERT(caption))     # (64,)
    c_t   = concat(traj_t, e)                 # control_dim = traj_dim + 64
    q_t   = concat(state_t, traj_t, e)        # query_dim = state_dim + traj_dim + 64

  2.3 Supervision for Projector x_star
  ------------------------------------
    V1 simple (allowed):
      x_star = x_t   # GT frame feature when q built from GT traj at t

    V1 better (preferred if time allows):
      Build a bank of x features; for each t, NN search with geometric
      distance on (state, traj) only; x_star = nearest frame feature
      (classical MM label). Then train Projector(q_with_text) → x_star

  2.4 Stepper target
  ------------------
    x_next = x_{t+1} of same clip (skip last frame of each clip)

3. GEOMETRY FEATURES (FROM new_joints) — IMPLEMENT
================================================================================

  Skeleton: 22 joints HumanML3D / SMPL-like.
  Use joint index 0 as root/pelvis unless standard HumanML3D layout says otherwise.
  Document joint indices in code comments.

  For each frame t (clip length T):

    root_pos[t] = joints[t, 0, :]  # (3,)

    Root velocity xz:
      if t < T-1: vel_xz = root_pos[t+1,[0,2]] - root_pos[t,[0,2]]
      else: vel_xz = 0

    Facing: from hip/shoulder or velocity direction; produce 2D unit vector
      face_xz (2,)

    Future trajectory (example horizons in frames at fps=20):
      offsets in frames: [4, 8, 12, 16, 20]  # ~0.2s..1.0s
      For each horizon h:
        if t+h < T: delta = root_pos[t+h,[0,2]] - root_pos[t,[0,2]]
        else: delta = last available or zeros
        rotate delta into facing-local frame → (2,)
      traj_t = concat all deltas  # traj_dim = 5*2 = 10  (or 10*2 if more horizons)

    Feet (optional but recommended):
      low joint indices for feet — use last joints if unknown; store height
      contact ≈ height < threshold

    state_t = concat(vel_xz, face_xz, foot_features...)

  Keep state_dim and traj_dim FIXED in config.yaml.

5. LOSSES (IMPLEMENT EXACTLY)
================================================================================

  L_decomp = MSE(Decompressor(x_t), y_t)

  L_step   = MSE(Stepper(x_t, c_t), x_{t+1})

  L_proj   = MSE(Projector(q_t), x_star)

  L_traj   = MSE(Text2Traj(e), traj_t)   # supervise Text2Traj with GT traj

  Optional:
  L_recon  = MSE(Decompressor(Projector(q_t)), y_star)
             where y_star is joints of matched frame (or y_t if x_star=x_t)

  Stage training (MUST support stages via CLI flag):

    Stage 1: only L_decomp
    Stage 2: L_step + L_traj
    Stage 3: L_proj (+ 0.1 * L_recon optional)

  Optimizer: AdamW
  Weight decay higher on Projector (e.g. 1e-2) than others (1e-4)
  Projector dropout ON

7. INFERENCE ROLLOUT (REQUIRED SCRIPT)
================================================================================

  Script: infer_rollout.py

  Input CLI:
    --prompt "a person walks forward"
    --frames 60          # output frames AT 30 fps after resample
    --seed 0
    --ckpt_dir ...

  Steps:
    1) e = TextProj(DistilBERT(prompt))
    2) traj = Text2Traj(e)
    3) init state from rest (zeros or mean pose joints)
    4) q0 = concat(state0, traj, e); x = Projector(q0)
    5) For t in range(T_native):
         y = Decompressor(x) → reshape (22,3)
         append y
         c = concat(traj, e)
         x = Stepper(x, c)
         every K frames: x = 0.5*x + 0.5*Projector(q_t)  # reproject optional
    6) Resample joint sequence from fps_native → 30 fps
    7) Save export .npz matching §8
